Description of folder:

/CountMatrix: for generating matrix counts for spatial and single-cell
/CellBender: to run CellBender for ambient RNA removal on single-cell data
/spatial: scripts for spatial data analysis
/single-cell: scripts for single-cell data analysis

config.sh files: to determine paths of base directories (where matrices, h5ad files are stored)
and output directories (where plots of analysis are stored)
